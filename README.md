# NXT CYBER v4.0 — AL-AMIN's AI Programmer

![Version](https://img.shields.io/badge/version-4.0-00ff41)

A cyberpunk-themed AI programming assistant with **built-in Python IDE**, **HTML live preview**, and **no-refusal AI**.

## ✨ Features

### 🎯 Core
- 🐍 **Python IDE** — write & run Python directly in browser (Skulpt)
- 🌐 **HTML Preview** — instant rendering of HTML/CSS/JS
- 💻 **Terminal Emulator** — 25+ commands, ASCII art, effects
- 🤖 **AI Programmer** — powered by Groq via Cloudflare Worker
- 🔓 **NO-REFUSAL MODE** — AI never says "sorry" or "I can't"

### 🎨 UI
- Matrix rain background (canvas)
- Scanline CRT effect
- Glitch animations
- Boot sequence with progress bar
- Hacker terminal aesthetic
- Dark/Light themes

### 🛠 Utilities
- 📋 Copy code with one click
- 💾 Download code as file
- ▶️ Run Python from chat directly
- 🖥️ Preview HTML from chat directly
- 🎤 Voice input (Bengali)
- 📎 File upload
- 📌 Pin messages
- 🔍 Search chat
- 📤 Export chat as Markdown
